01 — the shop as it is

Six machines.Six towers. And the cable between them.

Every control needs its own tower, its own serial card and its own run down the aisle. The longest here is 21 m. Move a machine and it gets longer.

02 — six separate points of failure

Nothing here is sharedexcept the problems

A dead tower stops one machine. A long run drops a transfer part-way. Each one is its own repair, its own walk across the floor, its own version of the file.

03 — what comes out

The towers go.The floor cable goes with them.

One Elecio mounts at each control. What remains of the serial run is a short jumper that stays connected, per machine.

04 — the link

One send,every control at once

The station pushes the program over the shop network. Each unit takes it at its own machine, at the same time, with nothing running between them along the floor.

05 — what replaces them

One PC. Or one phone.Handling all six.

Programs go from a single place to any control on the floor. The far corner of the shop is the same send as the machine beside the office.

06 — and it answers back

Every machine reportsto the same screen

Transfers, run time and the gaps between cycles come back from all six, so the state of the floor is one view instead of six walks.
